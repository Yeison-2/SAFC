# SAFC - Sistema de Administración de Fincas Cafeteras

SAFC es una solución móvil diseñada para modernizar y facilitar la gestión administrativa y operativa de fincas cafeteras. Esta aplicación permite a los caficultores llevar un control digital preciso de sus recursos, producción y finanzas directamente desde sus dispositivos Android.

## 🚀 ¿Qué resuelve SAFC?

Tradicionalmente, la gestión de pequeñas y medianas fincas cafeteras se realiza de forma manual o mediante registros en papel, lo que conlleva a la pérdida de información, errores en la liquidación de pagos y falta de estadísticas claras sobre la productividad. SAFC digitaliza estos procesos para:

- Eliminar el riesgo de pérdida de registros físicos.
- Agilizar la liquidación de pagos a recolectores.
- Proporcionar una visión clara de la producción diaria y acumulada.
- Facilitar el cumplimiento de compromisos mediante el envío de reportes automáticos.

## ✨ Funcionalidades Principales

- **Gestión de Empleados:** Registro completo de trabajadores, facilitando su identificación y asignación de labores.
- **Control de Producción:** Registro detallado de la cantidad de café recolectado por cada empleado, con soporte para diferentes unidades de medida.
- **Administración de Pagos:** Cálculo automático de salarios y liquidaciones basado en la producción registrada.
- **Reportes vía Email:** Configuración y envío de reportes de actividad y estados financieros directamente a los correos electrónicos registrados.
- **Modo Offline:** Funcionamiento garantizado sin conexión a internet mediante una base de datos local robusta (Room).
- **Interfaz Moderna:** Desarrollada con Jetpack Compose para una experiencia de usuario fluida e intuitiva.

## 🛠️ Tecnologías Utilizadas

- **Kotlin:** Lenguaje de programación principal.
- **Jetpack Compose:** Para la construcción de la interfaz de usuario moderna.
- **Room Database:** Persistencia de datos local.
- **Coroutines & Flow:** Gestión de procesos asíncronos.
- **JavaMail API:** Integración para el envío de correos electrónicos.
- **ViewModel & Navigation:** Arquitectura limpia y navegación estructurada.
